# calculator-tauri

This is a cross-platform desktop calculator application built using the Tauri framework and TypeScript. Tauri leverages web technologies to create lightweight, secure, and performant desktop applications.

## Features
* Basic arithmetic operations (addition, subtraction, multiplication, division).
* Responsive and intuitive user interface.
* Native desktop experience powered by Tauri.
* Developed with TypeScript for enhanced code quality and maintainability.

## Installation
To set up and run the calculator locally, ensure you have Rust and Node.js installed.

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/SummaryPuppet/calculator-tauri.git](https://github.com/SummaryPuppet/calculator-tauri.git)
    cd calculator-tauri
    ```
2.  **Install frontend dependencies:**
    ```bash
    npm install # or yarn install
    ```
3.  **Run in development mode:**
    ```bash
    npm run tauri dev
    ```
4.  **Build for production:**
    ```bash
    npm run tauri build
    ```
    (This will generate an executable in `src-tauri/target/release` or similar path.)

## Usage
Once the application is running or built, simply use the on-screen buttons to perform calculations.
